# Contributing

This is a personal project, but issues and pull requests are welcome.

- Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/PRIVACY.md](docs/PRIVACY.md) first. Changes that send anything about the reader off the laptop, or add a paid service, will not be merged.
- Run `npm test` before opening a pull request. See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
- Keep pull requests to one topic and add a line to `CHANGELOG.md` under "Unreleased".
- Only free-to-read sources. Do not add code that gets around paywalls.
